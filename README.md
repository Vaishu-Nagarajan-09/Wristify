# Wristify ⌚

A MERN Stack e-commerce watch website built as a 7-day development challenge.

## 🚀 7-Day Challenge

| Day   | Focus                                       | Status      |
| ----- | ------------------------------------------- | ----------- |
| Day 1 | Project Setup & Architecture                | Done        |
| Day 2 | Complete Homepage UI                        | Done        |
| Day 3 | Complete Cart & Wishlist Functionality      | Done        |
| Day 4 | Complete Product Details & Cart Integration | Done        |
| Day 5 | Authentication, Authorization & JWT         | Done        |
| Day 6 | Checkout & Orders                           | Done        |
| Day 7 | Final Integration, Testing & Deployment     | Done        |

## 🛠️ Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* Axios
* Bootstrap
* Git & GitHub
* Netlify
* Render
* MongoDB Atlas
