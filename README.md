# Wristify ⌚

A MERN Stack e-commerce watch website built as a 7-day development challenge.

## 🚀 7-Day Challenge

| Day | Focus | Status |
|-----|-------|--------|
| Day 1 | Project Setup & Architecture | Done |
| Day 2 | Complete HomePage UI | Done |
| Day 3 | Complete Cart and Wishlist Functionality | Done |
| Day 4 | Complete Product Details and Cart Integration | Done |
| Day 5 | Authentication and Authorization and JWT |

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Axios
- Bootstrap
- Git & GitHub
